# Pacote de prompts de arte — A Estrela Partida

Este pacote serve para gerar as artes pintadas nos sites gratuitos. Todos os prompts usam o mesmo
estilo, para os personagens combinarem entre si. Eles estão em inglês porque os geradores entendem
melhor; pode colar exatamente como está.

## Onde gerar de graça

| Site | Como usar |
| --- | --- |
| **Bing Image Creator** (bing.com/create) ou **Microsoft Designer** | Entre com uma conta Microsoft. Gera 4 opções por prompt, com cota diária gratuita. |
| **Leonardo.ai** | Cadastro gratuito com créditos diários. Escolha um modelo de "illustration" e a proporção indicada. |
| **Ideogram** (ideogram.ai) | Cota gratuita diária. Bom para a capa. |

## Como me enviar

1. Gere a imagem e escolha a melhor das opções.
2. Renomeie o arquivo com o nome indicado em cada personagem (ex.: `base.defensor.brasa.png`).
3. Anexe aqui na conversa (pode mandar várias de uma vez). Eu coloco no jogo, recorto e publico.

Dica: se um personagem sair diferente do esperado, gere de novo com o mesmo prompt. Para manter o
mesmo rosto entre versões, use a função de "variação" do próprio site.

> Os desenhos são originais da Estrela Partida. Não use nomes de outros jogos nos prompts.

## Miniaturas que andam (ciclo de caminhada de 8 quadros)

Cada personagem do tabuleiro tem `src/assets/arte/andar.<id>.webp`: uma faixa com 8 quadros
de caminhada, sem fundo. O jogo usa o quadro 3 (pernas juntas) para o personagem parado e
os 8 quadros quando ele anda casa por casa. Sem esse arquivo, aparece o token com o retrato.

Como gerar um novo (Bing Image Creator, proporção 3:2), trocando só a descrição:

```text
8-frame walk cycle sprite sheet, 8 frames arranged in 2 rows of 4, evenly spaced grid, the same character in every frame, side view walking to the right, frames show the full walk cycle: contact, down, passing, up, then the other leg, <DESCRIÇÃO DO PERSONAGEM>, full body from head to feet, hand-painted 3D tabletop miniature style, soft studio lighting, plain flat dark grey background, no text, no numbers, no logo, no watermark
```

Salve como `andar.<id>.jpg` numa pasta e rode:

```bash
python3 -I tools/miniaturas.py <pasta_com_os_jpg> src/assets/arte
```

O script tira o fundo cinza, separa os 8 quadros e alinha os pés.
Para personagens cinza ou escuros, troque o fundo por `plain flat solid bright green background, no shadows on the background`: o script também recorta fundo verde e remove os reflexos.
Companheiros (coruja, lince) entram na própria descrição para andarem junto.
