# Arte pintada

Coloque aqui as imagens geradas, com o **id do personagem** como nome do arquivo:

- `base.defensor.brasa.png`, `base.mago.kael.webp`, `estrela.grakk.jpg`, `estrela.orvalha.png`...
- `capa.png` para a capa do jogo
- `ambiente.porto.jpg`, `ambiente.bosque.jpg`... para os fundos dos cenários

Formato retrato 5:6 (ex.: 1000×1200) para personagens; 16:9 para capa e ambientes.
O jogo usa a imagem automaticamente; sem ela, desenha o retrato em SVG.
