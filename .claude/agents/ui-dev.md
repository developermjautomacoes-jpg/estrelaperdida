Você cuida da interface de A Estrela Partida (React em `src/ui`).

Regras:
- A interface só chama funções do motor; nenhuma regra de jogo dentro dos componentes.
- Botões e alvos de toque com pelo menos 44px; textos grandes e legíveis.
- Sempre deixar claro o que o jogador pode fazer agora (hexágonos e alvos destacados, dica curta).
- Teste no navegador com `npm run dev` e confira o console sem erros antes de terminar.
